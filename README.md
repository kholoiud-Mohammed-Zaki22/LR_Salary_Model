# Salary Prediction — Linear Regression

A linear regression model that predicts salary based on relevant input features, using a simple and interpretable machine learning approach.

## 📌 Overview
This project applies linear regression to model the relationship between salary and its predictive features. It covers data exploration, model training, and evaluation of prediction accuracy.

## 🧠 Approach
- Algorithm: Linear Regression
- Workflow: Data cleaning → exploratory data analysis → train/test split → model training → evaluation (e.g. R², MAE)

## 🛠️ Tech Stack
Python · Scikit-learn · Pandas · NumPy · Matplotlib

## 📂 Files
- Jupyter Notebook containing the full workflow: data exploration, preprocessing, model training, and evaluation metrics
